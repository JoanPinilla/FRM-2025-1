Rumba con el Roomba

Este proyecto tiene como objetivo la implementación de un sistema colaborativo de locomoción y guiado entre dos plataformas móviles autónomas: un robot iRobot Create 2 (Roomba) y un robot LEGO EV3, mediante comunicación no estructurada basada en señales ultrasónicas.

El Roomba será responsable de liderar el trayecto, emitiendo señales ultrasónicas de forma continua. El LEGO EV3, equipado con un sensor ultrasónico, interpretará esta señal como referencia para ajustar su desplazamiento y mantener el seguimiento del Roomba.

Aplicaciones

Aplicaciones actuales

Actualmente, el Roomba y el EV3 pueden generar rutinas de navegación colaborativa. Esto es útil para reducir la carga computacional de una de los robots y para simular comportamientos como el de Bug2. Sin embargo, teniendo en cuenta las limitaciones en el rango y la alineación específica que requieren los sensores para funcionar, se plantean nuevas aplicaciones:

Alineación a distancia

El sistema puede utilizarse para mantener alineados dos robots de forma autónoma, útil en tareas de seguimiento, desplazamientos sincronizados o formación en ambientes donde no se dispone de comunicación inalámbrica estructurada.

Juego de disparos con robots

Mediante sensores ultrasónicos e infrarrojos, se puede implementar una modalidad de juego entre robots donde uno actúa como perseguidor y otro como objetivo, integrando comportamientos de evasión, persecución y reacción a disparos. El reto de cada jugador sería alinear correctamente su sensor en el modo de emisión contra el sensor en modo escucha del otro jugador.
